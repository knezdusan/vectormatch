(c) **Gate 3 prevention:** Inngest step branches on `is_synthetic === true` → bypasses Persona-Match Gate 3 → routes to specialized `gpt-4o-mini` "Company-Culture Match" prompt (candidate vs `company_tech_stack` + remote policy metadata). (ii) "Intro / Connect" CTA routing target unspecified — Cord company-level portal (cross-blueprint wiring) or internal express-interest form?

## Blueprint 3: The Inbound "Direct-to-Founder" Loop
*(Focuses on bypassing ATS entirely by replicating RemoteOK/Cord inbound loops.)*

- **Target Source(s):** VectorMatch's existing 10K-company Greenhouse/Lever/Ashby corpus (seed for claimable profiles). *(Survived R1–R3 as seed source. R3 note: Architect flagged actual poller scale may be ~449 companies/12h — corpus-size discrepancy to reconcile before publishing any aggregate stat.)*
- **Growth/Inbound Mechanism:** [Pending — paradox resolved, residual issues narrowing]
  - *Sub-option 3A (Architect R2+R3 — primary, resolved):* Supply-side **"Fit Score"** — Gate 3 arbiter scores the job posting alone against a global-remote rubric (async-friendliness, explicit geo/timezone language, comp transparency, absence of hidden HQ-proximity requirements). Output: `remote_friendliness_score` (0–100) + 1-line rationale. Cold email hook: *"Your listing scores 82/100 on our Global Remote Fit index — claim it to see how CEE candidates would evaluate it once matched."* **Survived R3.**
  - *Gate 3 prompt distinction (Architect R3 — resolved):* Two distinct prompt templates — **Fit Score** (input: job posting only; task: score vs remote-fit rubric; output: `{fit_score, flags, rationale}`; runs once per job on ingest; cacheable) vs **Persona-Match** (input: job + candidate persona; task: score candidate-job fit; output: `{match_score, gate3_verdict, rationale}`; runs per candidate×job pair; non-cacheable). Schema: `jobs.fit_score` vs `job_matches.gate3_verdict`. **Survived R3 — conflation risk eliminated.**
  - *Sub-option 3B (Architect R3 — demoted):* Aggregate benchmark signal: *"X% of remote listings fail global-remote fit."* **Demoted R3 from "fallback" to "deferred":** Benchmark N estimated at 1,300–2,200 scoreable listings (449 companies × 3–5 reqs) — statistically thin for a public percentage claim. Deferred until corpus reaches N>5,000 scoreable listings. Architect recommends logging actual open-posting count from existing poller before publishing.
  - *Indexing policy (Architect R2+R3 — resolved):* Pre-claim pages: `noindex, follow` (thin/duplicate content + unverified-claim risk). Post-claim: `index, follow`. Outbound ATS/career-page links: `follow` + `rel="noopener"` (legitimate canonical links; `nofollow` would undermine claimed page's credibility). **Survived R3.**
- **Incentive Structure:** [Pending — partially resolved] R2 reframe: hook sells the audit/badge ("your Fit Score"), not candidate count — consent-first framing. **Survived R3–R5 as concept.** **R4 cost model (Architect):** $0.00027/listing (1,200 input + 150 output tokens, gpt-4o-mini); $0.35–$0.60/cycle at current scale (1,300–2,200 listings), $0.80–$2.16/cycle at 10K scale (3,000–8,000 listings). **R4 cost optimization (survived R5):** (1) Dedup gate — hash JD text, only re-score if changed (cuts 80–90% of calls after initial backfill); (2) Regex auto-fail — explicit geo-fence/on-site patterns → `fit_score: 0-10`, skip LLM; (3) Regex auto-pass-candidate — strong async/anywhere signals → lighter LLM prompt; (4) Remainder → full Fit Score LLM. **R5 resolutions (Architect):** (a) Lighter rubric prompt defined — *retains:* comp-transparency scoring, hidden-clause detection, rationale generation; *drops:* binary geo-restriction re-check (regex already resolved), async-signal re-scoring (regex already matched), full 0–100 reasoning chain (collapsed to 3-tier `high/medium/low` + numeric midpoint). ~40% shorter input. (b) Marketing-vs-implementation resolved — **mandate LLM for any publicly-displayed passing score** (full or lighter rubric); regex-only auto-fails (score 0–10) allowed publicly since "detected hard geo-restriction" is a defensible mechanical claim; regex may never auto-generate a passing/high score or public rationale without LLM. (c) Multilingual regex added R5: DE/FR/NL/PL hard-fail + positive-signal patterns; contradictory-signal (hard-fail + positive both fire) → full rubric LLM; low language-detection confidence → full rubric. **R6 resolutions (Architect):** (i) **Contradictory-signal EU escalation rate estimated:** 15–25% of EU-scraped listings will fire both hard-fail + positive-signal patterns (EU postings frequently mix "remote möglich" + "vor Ort bevorzugt"); blended call-reduction revised from ~85% to **75–80%** overall (60–70% on EU subset vs 80–90% on US-centric corpus). Cost impact: material but not cost-breaking (still sub-$5/day at current scale). Caveat: reasoned estimate, not measured — first EU-corpus backfill must log actual dual-fire rate before treating as fixed. (ii) **3-tier precision resolved:** Keep one 0–100 public scale for brand consistency; internally store scoring path; reveal methodology on hover/detail view ("Fit assessed via expedited review" for lighter-rubric scores, full disclosure for full-rubric). Do **not** display tier labels as primary artifact — would visibly signal two-tier quality system. **R6 known limitation (non-blocking):** Methodology footnote invisible at side-by-side comparison point (two claimed pages with identical "85/100" headlines in search results) — acknowledged as low-severity trust risk.
- **VectorMatch Pipeline Integration:** Repurpose existing gpt-4o-mini Gate 3 arbiter as "Verified Global Remote" badge scorer (Fit Score prompt template — distinct from Persona-Match); store `remote_friendliness_score` + rationale in `jobs.fit_score`; surface as badge on claimed pages. *(Survived R3–R6; scoring rubric: async-friendliness, geo/timezone language, comp transparency, HQ-proximity absence. Cost model + optimization pipeline resolved R4–R5. Lighter-rubric prompt + LLM-mandate-for-public-scores resolved R5. EU escalation rate + 3-tier precision resolved R6 with known limitation documented. All fields survived Red Team.)*
